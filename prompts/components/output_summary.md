## Output Format

Write a concise summary in **past tense**, ≤150 words, structured as:

1. **What was asked** — restate the query in one sentence
2. **What was found** — specific numbers, tickers, dates; no vague language
3. **Gaps or caveats** — data that could not be retrieved or verified
4. **Tools used** — comma-separated list

No raw tool output. No markdown headers. Plain prose only.
